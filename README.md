# Adventure

A choose-your-own-adventure game made in [Twine](https://twinery.org/) (Harlowe 3.3.9 story format).

**Play it:** https://williamlmorrison.github.io/Claude-Twine/

## Files
- `index.html` — the game, published from Twine (Build → Publish to File). This is both the source and the page served by GitHub Pages.
- `assets/Background.png` — the background scene, referenced from the Story Stylesheet.

## Updating
Edit the story in Twine, publish it to a file, and save that file over `index.html`.
To bring this version into Twine, use Library → Import and choose `index.html`.
